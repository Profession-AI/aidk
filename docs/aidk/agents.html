AIDK Agents Package

This package provides a comprehensive set of agentic loop implementations that support real-time streaming responses during the entire generation phase. The agents are designed to work with various AI paradigms and can process user queries through iterative reasoning, tool usage, and structured output generation.

Key Features:

  • Real-time streaming of AI responses
  • Multiple agent paradigms (React, Function Calling, Plan-and-Execute, etc.)
  • Step-based reasoning format for transparent decision making
  • Tool integration and execution
  • Configurable iteration limits and debugging
  • Asynchronous streaming with proper resource management

Agent Paradigms: The agents use a structured step-based format for reasoning:

  • Thought N:
  • Action N: {"name": "tool_name", "arguments": {...}}
  • Observation N:
  • Final answer:

Streaming Architecture: Streaming allows real-time processing of AI responses as they are generated, enabling:

  • Immediate feedback to users
  • Progress monitoring during long operations
  • Better user experience with responsive interfaces
  • Debugging and monitoring of agent reasoning

Usage Examples:

  1. Basic React Agent with Streaming:

    from aidk.agents import Agent

agent = Agent(model, paradigm="react")
agent.enable_streaming()  # Uses default console output
result = agent.run("What is the capital of France?")

  2. Custom Streaming Handler:

    from aidk.agents import Agent
import json

def custom_stream_handler(content):
    # Process streaming content in real-time
    print(f"Streaming: {content}", end='', flush=True)

agent = Agent(model, paradigm="react")
agent.enable_streaming(custom_stream_handler)
result = agent.run("Your query here")

  3. Function Calling Agent:

    from aidk.agents import Agent
from aidk.tools import search_web

agent = Agent(model, paradigm="function_calling")
agent.register_tools([search_web])
agent.enable_streaming()
result = agent.run("Search for recent AI news")

  4. Plan and Execute Agent:

    agent = Agent(model, paradigm="plan-and-execute")
agent.enable_streaming()
result = agent.run("Create a detailed project plan")

Available Agent Types:

  • FunctionCallingAgenticLoop: Native OpenAI function calling
  • ReactAgenticLoop: ReAct reasoning pattern
  • ReactWithFCAgenticLoop: Hybrid ReAct + Function Calling
  • ProgrammaticAgenticLoop: Code generation and execution
  • PlanAndExecuteAgenticLoop: Planning then execution pattern
  • ReflexionAgenticLoop: Self-reflection and improvement
  • SelfAskAgenticLoop: Self-questioning approach
  • SelfAskWithSearchLoop: Self-ask with web search capabilities

Streaming Callback Format: The streaming callback receives content as plain text strings. For advanced use cases, you can access the raw streaming data through the model's streaming methods.

Error Handling:

  • Automatic fallback to non-streaming mode on errors
  • Proper cleanup of async resources
  • Configurable debug output
  • Iteration limits to prevent infinite loops

Thread Safety: This implementation is designed for single-threaded use. For concurrent access, create separate agent instances for each thread or process.

206    def _get_base_messages(self, agent_type: str, query: str) -> List[Dict[str, Any]]:
207        """Generate base messages for the specific agent type.
208        
209        This method creates the initial message structure for the agent,
210        including the appropriate prompt template and user query. The
211        prompt template is selected based on the agent type and includes
212        information about available tools.
213        
214        Parameters
215        ----------
216        agent_type : str
217            Type of agent to determine which prompt template to use
218        query : str
219            User query to include in the prompt
220        
221        Returns
222        -------
223        List[Dict[str, Any]]
224            List of base messages for the agent, including the prompt and query
225        """
226        tools = self._get_tools()
227        prompt_data = {"available_tools": tools}
228        
229        # Handle case where _agentic_prompt is already a Prompt object
230        if self._agentic_prompt is not None and hasattr(self._agentic_prompt, 'as_dict'):
231            # It's already a Prompt object, just update the data and return
232            agentic_prompt = self._agentic_prompt
233            # Update prompt data if the prompt supports it
234            if hasattr(agentic_prompt, 'prompt_data'):
235                agentic_prompt.prompt_data = prompt_data
236        else:           
237            # Otherwise, determine prompt configuration and create new Prompt
238            prompt_config = self._determine_prompt_config(agent_type)
239            
240            agentic_prompt = Prompt(
241                **prompt_config,
242                is_system=True,
243                prompt_data=prompt_data
244            )
245
246        messages = [agentic_prompt.as_dict()]
247
248        if isinstance(query, Prompt):
249            messages.append(query.as_dict())
250        else:
251            messages.append({"role": "user", "content": query})

346    def _parse_step_format(self, content: str) -> Optional[Dict[str, Any]]:
347        """Parse the step-based format <STEP_TYPE>: <RESULT>.
348        
349        This method parses agent responses that follow the structured step format
350        used by ReAct and similar reasoning patterns. It extracts the step type,
351        step number, and content from formatted responses.
352        
353        Supported step types:
354        - Thought: Reasoning and analysis steps
355        - Action: Tool calls and actions (must be valid JSON)
356        - Observation: Results from tool executions
357        - Final answer: Conclusive responses to user queries
358        
359        Special handling: 
360        - If content contains both "Thought" and "Action", the Action will be returned with priority.
361        - If content contains both "Thought" and "Final answer", the Final answer will be returned with priority.
362        
363        Parameters
364        ----------
365        content : str
366            Content to parse in the format <STEP_TYPE>: <RESULT>
367        
368        Returns
369        -------
370        Optional[Dict[str, Any]]
371            Dictionary containing:
372            - step_type: Type of step (thought, action, observation, final answer)
373            - step_number: Optional step number if present
374            - content: Step content
375            - action: Parsed action data (for action steps)
376            - final_answer: Final answer content (for final answer steps)
377            Returns None if parsing fails
378        """
379        if not content or not isinstance(content, str):
380            return None
381        
382        content = content.strip()
383        
384        # Check for multiple step types and prioritize accordingly
385        lines = content.split('\n')
386        action_start = None
387        thought_start = None
388        final_answer_start = None
389        
390        # Find the start lines for Action, Thought, and Final answer
391        for i, line in enumerate(lines):
392            if re.match(r'^Action(?:\s+\d+)?\s*:', line, re.IGNORECASE):
393                action_start = i
394            elif re.match(r'^Thought(?:\s+\d+)?\s*:', line, re.IGNORECASE):
395                thought_start = i
396            elif re.match(r'^Final answer(?:\s+\d+)?\s*:', line, re.IGNORECASE):
397                final_answer_start = i
398        
399        # Priority: Final answer > Action > Thought
400        if final_answer_start is not None:
401            # Final answer has highest priority
402            step_type = "final_answer"
403            
404            # Extract step number from Final answer line
405            final_answer_line = lines[final_answer_start]
406            step_number_match = re.search(r'Final answer\s+(\d+)\s*:', final_answer_line, re.IGNORECASE)
407            step_number = step_number_match.group(1) if step_number_match else None
408            
409            # Extract content from Final answer (everything after the colon on the first line)
410            final_answer_content = final_answer_line.split(':', 1)[1].strip()
411            
412            # Add all subsequent lines until we hit another step type or end
413            i = final_answer_start + 1
414            while i < len(lines):
415                line = lines[i].strip()
416                if re.match(r'^(Thought|Action|Observation|Final answer)(?:\s+\d+)?\s*:', line, re.IGNORECASE):
417                    break
418                if line:  # Only add non-empty lines
419                    final_answer_content += '\n' + line
420                i += 1
421            
422            step_content = final_answer_content.strip().replace("```json", "").replace("```", "")
423            
424            result = {
425                "step_type": step_type,
426                "step_number": step_number,
427                "content": step_content,
428                "final_answer": step_content
429            }
430            
431            return result
432            
433        elif action_start is not None and thought_start is not None:
434            # Both Thought and Action present, prioritize Action
435            step_type = "action"
436            
437            # Extract step number from Action line
438            action_line = lines[action_start]
439            step_number_match = re.search(r'Action\s+(\d+)\s*:', action_line, re.IGNORECASE)
440            step_number = step_number_match.group(1) if step_number_match else None
441            
442            # Extract content from Action (everything after the colon on the first line)
443            action_content = action_line.split(':', 1)[1].strip()
444            
445            # Add all subsequent lines until we hit another step type or end
446            i = action_start + 1
447            while i < len(lines):
448                line = lines[i].strip()
449                if re.match(r'^(Thought|Action|Observation|Final answer)(?:\s+\d+)?\s*:', line, re.IGNORECASE):
450                    break
451                if line:  # Only add non-empty lines
452                    action_content += '\n' + line
453                i += 1
454            
455            step_content = action_content.strip().replace("```json", "").replace("```", "")
456            
457            result = {
458                "step_type": step_type,
459                "step_number": step_number,
460                "content": step_content
461            }
462            
463            # Parse action data (must be JSON)
464            try:
465                action_data = json.loads(step_content)
466                result["action"] = action_data
467            except json.JSONDecodeError:
468                # If not valid JSON, keep content as raw string
469                result["action"] = {"raw": step_content}
470            
471            return result
472        
473        # Standard single step parsing
474        step_pattern = r'^(Thought|Action|Observation|Final answer)(?:\s+(\d+))?\s*:\s*(.*)$'
475        match = re.match(step_pattern, content, re.IGNORECASE | re.DOTALL)
476        
477        if match:
478            step_type = match.group(1).lower()
479            step_number = match.group(2) if match.group(2) else None
480            step_content = match.group(3).strip().replace("```json", "").replace("```", "")
481            
482            result = {
483                "step_type": step_type,
484                "step_number": step_number,
485                "content": step_content
486            }
487            
488            # Special handling for Action steps (must be JSON)
489            if step_type == "action":
490                try:
491                    action_data = json.loads(step_content)
492                    result["action"] = action_data
493                except json.JSONDecodeError:
494                    # If not valid JSON, keep content as raw string
495                    result["action"] = {"raw": step_content}
496            
497            # Special handling for Final answer steps
498            elif step_type == "final_answer":
499                result["final_answer"] = step_content
500            
501            return result
502

AI Agent that implements different reasoning paradigms for autonomous task execution.

The Agent class provides a unified interface for creating and using AI agents with various reasoning paradigms. It acts as a high-level wrapper around specific agentic loop implementations, offering a consistent API regardless of the underlying reasoning pattern.

The agent can be configured with different reasoning approaches, tools, and execution parameters to handle complex tasks autonomously or with human oversight.

Parameters
  • model (Model): AI model instance to use for agent execution
  • tools (list, optional): List of available tools for the agent. Each tool should be a callable function. Default is None.
  • paradigm (str or _AgenticLoop, optional): Reasoning paradigm to use. Default is "function_calling".
  • agent_prompt (str, optional): Custom prompt for the agent. If None, uses the default prompt for the chosen paradigm. Default is None.
  • name (str, optional): Name identifier for the agent. Default is empty string.
  • mcp_servers (list, optional): List of MCP (Model Context Protocol) servers to register. Default is None.
  • debug (bool, optional): Flag to enable debug output during execution. Default is False.
  • max_iter (int, optional): Maximum number of iterations allowed for the agent. If None, there are no limits. Default is None.
  • native_web_search (str, optional): Native web search capability level. Must be one of: "low", "medium", or "high". Default is None.
  • human_feedback (str, optional): Human feedback mode for controlling agent execution. Can be:
    • None: No human feedback required (default)
    • "actions": Pause and request confirmation before executing tool actions
    • "all": Pause after every step for human review Default is None.
Attributes
  • name (str): Name identifier for the agent
  • _model (Model): The AI model instance used for execution
  • _loop (_AgenticLoop): The agentic loop implementation for the chosen paradigm
Supported Paradigms
  • function_calling: Native OpenAI function calling with tool integration
  • react: Reasoning and Acting pattern with iterative problem solving
  • react_with_function_calling: Combines ReAct reasoning with function calling
  • plan-and-execute: Two-phase approach: planning then execution
  • programmatic: Code generation and execution for computational tasks
  • reflexion: Self-reflective reasoning with error correction
  • self_ask: Self-questioning approach for complex reasoning
  • self_ask_with_search: Self-ask with web search capabilities
